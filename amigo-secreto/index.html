    Pronto! Mande cada link para a pessoa certa

    Etiquetas e cartões pra imprimir

    Uma etiqueta “Para:” com o nome de cada pessoa (o presente chega anônimo até a revelação) + um cartão de pistas para cada um. Prévia grátis:

    Imprimir sem a marca “PRÉVIA”

    • Etiquetas de presente com o nome de cada participante (10 por folha A4)
    • Cartão de pistas “Meu amigo secreto é…” para a revelação
    • Sem nenhum logo — só o nome do seu grupo

    Pagamento único pelo Mercado Pago: Pix ou cartão. O sorteio continua grátis.

    Liberado 🎉

    Imprima ou salve em PDF (no celular: Compartilhar → Imprimir → salvar PDF).

    Como funciona

    1. Escreva os nomes e, se quiser, quem não pode tirar quem.
    2. Toque em sortear: sai um link para cada pessoa.
    3. Mande cada link no WhatsApp da pessoa (o botão já abre a conversa com a mensagem pronta).
    4. Cada um abre o seu, vê quem tirou e monta a lista de desejos pro grupo.

    Perguntas frequentes

    Quem organiza consegue ver quem tirou quem?

    Não. O resultado vai escondido dentro de cada link e a tela do organizador mostra só os nomes. Só dá pra saber abrindo o link de outra pessoa — por isso, não abra.

    Precisa de cadastro, e-mail ou telefone?

    Não. Ninguém precisa criar conta nem instalar nada. Os nomes ficam só nos links e no seu aparelho — não guardamos o sorteio num servidor.

    Dá pra impedir que o casal se tire?

    Dá. Em “quem não pode tirar quem”, escreva um par por linha (ex.: “Ana e Beto”). O sorteio respeita os dois sentidos e ninguém tira a si mesmo.

    E a lista de desejos?

    Quem recebe o link monta a própria lista (até 6 itens) e manda no grupo. Cada item vira um botão que abre a busca na Shopee e no Mercado Livre.

    É grátis mesmo?

    O sorteio, os links e a lista de desejos são grátis, sem limite de participantes razoável (até 60). Pago é só o kit opcional de etiquetas e cartões pra imprimir, R$9,90.
